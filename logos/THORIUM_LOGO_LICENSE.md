This notice does not apply merely because a file is stored under `logos/`.

covered Thorium logo artwork are:

- Chromium and other third-party logos;
- photographs, screenshots, documentation illustrations, and unrelated UI
  icons;
- historical Technetium artwork;
- Thorium source code and scripts;
- files identified as Apache-licensed or Chromium BSD-licensed.

unless a file or directory carries a more specific notice.
